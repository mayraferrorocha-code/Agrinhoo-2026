# Agrinho 2026

## Tema
Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.

## Assunto Escolhido
Uso consciente da água na agricultura.

## Sobre o Projeto
Este projeto foi desenvolvido para o Concurso Agrinho 2026, na categoria Programação Web.
A aplicação apresenta soluções para a preservação dos recursos hídricos no campo e traz um simulador interativo para cálculo de economia de água na irrigação.

## Objetivo
Demonstrar como a tecnologia e as boas práticas agrícolas contribuem para a produção sustentável e preservação ambiental.

## Tecnologias Utilizadas
- HTML5
- CSS3 (Design Responsivo)
- JavaScript (Manipulação do DOM)
- Inteligência Artificial como apoio no desenvolvimento

## Funcionalidades
- Interface educativa sobre irrigação eficiente.
- Simulador dinâmico de economia de água.
- Layout responsivo para celular e computador.
